# Synthetic kata wing

These five opt-in defects are deterministic teaching material, not discovered
bugs. Exactly one package feature may be enabled at a time. Every kata prints a
startup warning, emits `SyntheticKataEnabled`, types artifacts and receipts with
`synthetic=true`, and writes only the distinct `# cc-kata-ledger-v1` format.
Production summaries, badges, imports, and museum exhibits reject that type.

The fixed campaign configuration on every page is profile `rough`, config hash
`23b166788e01ba12`, and seed range `0x0..0x1`. `./scripts/ci/kata-matrix.sh`
checks the default build, the expected pairwise compile failure, every owning
detector, every forwarding build, and every synthetic trace marker.
