# 08 — A flight recorder is a teaching surface

The theater is intentionally instrument-like. Canvas2D owns the topology and
timeline so the visual hot paths do not become a second state machine; React
owns controls and inspection. Every interaction has a seed/profile shape that
can be put in a URL, and memory checkpoint buttons make the scrub contract
visible even before a large live trace is loaded.

The museum is empty until a trace earns a pinned build and a written root
cause. That blank state is useful: it tells visitors that the catalogue is an
archive of evidence, not a collection of planted demos.
